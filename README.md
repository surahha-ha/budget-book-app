# 우리집 가계부 (Budget Book)

가족 공동 가계부 — **엑셀로 완성**, **웹앱 전환 계획** 진행 중인 프로젝트.

| `Code.gs` | **구글 시트용 Apps Script** — 파일 업로드 없이 코드만으로 동일 가계부 생성 |

## 🚀 빠른 시작 (엑셀 재생성)
```bash
pip install openpyxl
python build_budget.py          # → 우리집_가계부.xlsx 생성
```
> openpyxl 저장본은 수식 문자열만 들어있어, Excel/LibreOffice로 한 번 열면 값이 자동 계산됩니다.

## 📲 구글 시트로 옮기기 (파일 업로드 없이)
업로드가 막힌 환경에서도 **코드(텍스트)만으로** 구글 시트에 동일한 가계부를 만들 수 있습니다.
1. 구글 시트 새 문서 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 전부 붙여넣고 저장(Ctrl+S)
3. 함수 목록에서 **`buildBudget`** 선택 → ▶ 실행 (최초 1회 권한 승인)
4. 시트로 돌아오면 6개 시트가 생성됨

> 차트 막대별 색·집행률 데이터바 등 일부는 구글 차트 한계로 다르게 표현됩니다(`Code.gs` 상단 주석 참고).

## 🎨 디자인 & 기능
- 연두 헤더 + 파스텔 KPI 카드 + 카테고리 14색 막대 + 진노랑 포인트 (맑은 고딕)
- 월간 대시보드(KPI 6 + 차트 3), 주/월/분기/연 리포트, 자동 진단(신호등), 정기지출 체크리스트
- 거래내역 자동필터 · 수입행 색구분 · 시트 보호(입력칸만 편집)
- 저축률 = (수입 − 소비지출) / 수입
